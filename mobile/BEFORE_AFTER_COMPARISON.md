## 🔍 أمثلة الحالات الحقيقية

### الحالة 1: مستخدم مع WiFi 5GHz ممتاز

**قبل التصحيح:**
```
المستخدم: "لدي WiFi قوي جداً"
التطبيق:
  0s    → بدء فحص الخادم
  5s    → لا توجد استجابة سريعة
  10s   → timeout → "offline!"
  المستخدم يرى: فاتورة محفوظة محلياً ❌ (خاطئ!)
```

**بعد التصحيح:**
```
المستخدم: "لدي WiFi قوي جداً"
التطبيق:
  0s    → بدء فحص /health
  0.1s  → استجابة سريعة
  3s    → "online!" ✅
  المستخدم يرى: فاتورة محفوظة على الخادم ✅ (صحيح!)
```

---

### الحالة 2: مستخدم مع 4G/LTE

**قبل:**
```
4G متوسط → قد يصير timeout → offline ❌
```

**بعد:**
```
4G متوسط → يتحقق من health → online ✅
```

---

### الحالة 3: مستخدم بدون اتصال (Airplane Mode)

**قبل:**
```
0s    → بدء الفحص
10s   → timeout → offline ❌
إجمالي انتظار: 10 ثواني (بطيء!)
```

**بعد:**
```
0s   → بدء الفحص
<1s  → فشل فوري → offline ✅
إجمالي انتظار: <1 ثانية (سريع!)
```

---

### الحالة 4: اتصال سيء جداً (ضعيف/متقطع)

**قبل:**
```
قد يصير:
- online ثم offline
- timeout مع بيانات فقدت
- سلوك غير متوقع
```

**بعد:**
```
✅ يحاول 3 مرات مع تأخير متزايد
✅ إذا فشل: fallback محلي
✅ لن تفقد البيانات أبداً
```
