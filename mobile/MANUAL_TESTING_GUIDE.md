# 🧪 دليل الاختبار اليدوي السريع

## ✅ قبل البدء

- [ ] قم بتثبيت التطبيق على جهاز أو محاكي
- [ ] سجّل الدخول بحساب تجريبي
- [ ] تأكد من وجود فواتير معلقة (HORS LIGNE)

---

## 🎬 السيناريو الأساسي

### الخطوة 1: التحضير

1. افتح التطبيق
2. انتقل إلى شاشة الفواتير (Factures)
3. انقر على تبويب "Hors ligne"

**المتوقع:**
```
✅ تبويب "Hors ligne" مختار
✅ عدد الفواتير: 18 (مثلاً)
✅ كل فاتورة تعرض شارة برتقالي "HORS LIGNE"
```

---

### الخطوة 2: بدء المزامنة

1. انقر الزر "Synchroniser"
2. راقب الشاشة

**المتوقع أثناء المزامنة:**
```
⏳ الزر يصبح معطل
⏳ يظهر مؤشر تحميل (spinner)
⏳ الرسالة: "Synchronisation en cours..."
```

---

### الخطوة 3: النتيجة - الجزء الحاسم ✨

**هذا هو الجزء الذي تم تحسينه!**

#### المتوقع فوراً بعد النجاح:
```
✅ الرسالة: "Sync: 18 succès"
✅ شارة "HORS LIGNE" تختفي على الفور
✅ تبويب "Hors ligne" يصبح فارغاً
✅ الفواتير تنتقل إلى "Tout"
⚡ كل هذا في أقل من 100 ميلي ثانية!
```

#### ثم:
```
📥 التحميل من الخادم (2-3 ثواني)
✅ تأكيد البيانات من الخادم
```

---

## 📋 قائمة المراجعة

### بعد المزامنة الناجحة:

- [ ] الرسالة تقول "Sync: X succès"
- [ ] شارة "HORS LIGNE" اختفت
- [ ] الفواتير لم تعد في "Hors ligne"
- [ ] الفواتير تظهر في "Tout"
- [ ] عدد الفواتير في "Hors ligne": 0
- [ ] لم تحدث أخطاء

### اختبر التبديل بين التبويبات:

1. انقر "Tout" → تظهر جميع الفواتير بدون شارة ✅
2. انقر "Hors ligne" → قائمة فارغة ✅
3. انقر "Tout" مجدداً → جميع الفواتير بدون شارة ✅

---

## 🔍 الاختبارات الإضافية

### اختبار 1: مزامنة جزئية (محاكاة)

**المتطلب:** فشل جزئي في المزامنة

**التوقع:**
```
✅ الفواتير الناجحة: شارة تختفي فوراً
❌ الفواتير الفاشلة: الشارة تبقى
📊 عدد الفواتير في "Hors ligne": يقل
```

### اختبار 2: بدون إنترنت

**المتطلب:** افصل الإنترنت وحاول المزامنة

**التوقع:**
```
❌ الرسالة: "Erreur de synchronisation"
❌ الفواتير: تبقى بدون تغيير
📊 "Hors ligne" count: لم يتغير
```

### اختبار 3: اتصال بطيء

**المتطلب:** اتصال 3G أو WiFi ضعيف

**التوقع:**
```
✅ التحديث الفوري يحدث على الفور (محلي)
⏳ التحميل من الخادم يحدث لاحقاً
📊 المستخدم يرى التحديث بدون انتظار
```

---

## 🎯 معايير النجاح

### ✅ يجب أن تحدث جميع هذه الأشياء:

1. **التحديث الفوري:**
   - [ ] الشارة تختفي في <100ms
   - [ ] الفواتير تنتقل من "Hors ligne"
   - [ ] الواجهة تتحدث بدون تأخير

2. **الموثوقية:**
   - [ ] لا فقدان للبيانات
   - [ ] لا أخطاء في الكود
   - [ ] لا تعليق للتطبيق

3. **تجربة المستخدم:**
   - [ ] واضح أن المزامنة نجحت
   - [ ] لا التباس حول الحالة
   - [ ] رد فعل فوري ومرضي

---

## 🐛 استكشاف الأخطاء

### المشكلة: الشارة لا تزال تظهر

**الحلول المحتملة:**
```
1. تأكد من أن copyWith يعمل:
   invoice.copyWith(isPending: false) ✅

2. تأكد من استدعاء _applyFilters():
   setState(() { _applyFilters(); }) ✅

3. تحقق من المنطق:
   إذا isPending = false، الشارة يجب أن تختفي
```

### المشكلة: التطبيق يتعليق

**الحلول المحتملة:**
```
1. تحقق من عدد الفواتير:
   إذا كثير جداً، قد يكون بطيء

2. تحقق من الاتصال:
   إذا كان بطيء، المزامنة ستستغرق وقت

3. تحقق من السجلات:
   flutter logs | grep -i error
```
